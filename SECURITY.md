# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue. Use GitHub's
private vulnerability-reporting flow when available. Otherwise contact the
maintainers privately with the affected release or commit, a minimal
reproduction, impact, and the command limits used.

Reports involving local-path policy bypasses, unexpected network access,
resource-limit bypasses, malformed Turtle/shapes accepted as conforming, or
invalid JSON output are especially useful.
